# Инструкция по начальной настройке
 
## Доработки конфигурации «Управление IT-фирмой для компании «Ваш компьютерный мастер»

## Введение

По техническому заданию Заказчика был разработан новый функциональный модуль по Обслуживанию клиентов и модуль для Расчёта управленческой заработной платы. Все добавленные константы, справочники, документы, обработки и отчеты в рамках разработанных модулей размещены в новой служебной подсистеме «Добавленные объекты». Данная система в полном объеме доступна только пользователю с правами Администратора.

4. Номенклатура Работы специалиста

## Необходимые настройки для работы с новым функционалом:
### В режиме Администратора необходимо выполнить следующие действия:
1. Создать группу и бота в Телеграмм. Они нужны для отправки уведомлений специалистам о созданных документах "Обслуживания клиентов".
Уведомления создаются автоматически при создании/изменении документа "Обслуживания клиентов". Заполнить константы Токен управления Телеграм-ботом и Идентификатор группы оповещений.
2. В подразделе Сервис заполнить константы "Номенклатура Абонентская плата" и "Номенклатура Работы специалиста"  значениями "Абонентская плата" и "Работы специалиста" соответственно из справочника Номенклатуры.
Если таких наименований нет в справочнике, сохдайте их. В дальнейшем из данных констант будут проставляться по умолчанию услуги в документ Реализация товаров и услуг.

4. Настроить права доступа сотрудникам

## Интеграция с Телеграм и заполнение констант для интеграции с 1С
### Создание бота
1. Напишете в Телеграм https://t.me/BotFather команду "/start"
2. Напишите команду "/newbot"
3. Выберите имя вашего бота, которое будут видеть пользователи
4. Выберите идентификатор вашего бота (он должен заканчиваться на "bot")
5. Скопируйте токен, который пришлет BotFather
6. В 1С откройте подсистему "Добавленные объекты" подраздел "Сервис" и сохраните скопированный токен в константу "Токен управления Телеграм-Ботом".

### Создание группы
Создайте группу в Telegram
Добавьте в группу только что созданного бота
Назначьте боту права администратора
Добавьте в группу специалистов

Что бы получить идентификатор группы выполните следующие действия:
- Напишите любое сообщение в группу
- С помощью браузера или Postman выполните запрос https://api.telegram.org/bot[ВашТокен]/getUpdates.
- В полученном JSON найдите идентификатор группы, в которой получено сообщение, и скопируйте его
- В 1С откройте подсистему "Добавленные объекты", раздел "Сервис", и сохраните скопированный идентификатор в константе «Идентификатор группы оповещения».

## Настройка Графика работы
В справочник "Графики работы" заведите необходимый вид графика (пятидневка/шестидневка). В подсистеме "Сервис" выберите обработку "Заполнение графика работы". 
В поле "Период" выберите период (Год), в поле "Выходные дни" через запятую перечислите номера выходных дней недели. Например, 6,7 (при пятидневки - это суббота и воскресенье).
Поле "График работы" заполните видом графика. Нажмите "Заполнить". В регистре "График работы" проверте корректность заполнения графика на год. 

## Регистр сведений "Условия оплаты сотрудников"
Заполните регистр сведений "Условия оплаты сотрудников", укажите оклад у всех сотрудников и процент от работы у Специалистов.

------
## Настройка прав доступа сотрудникам
1. Для пользователя Бухгалтрер установите права Бухгалтер ИТ фирмы. Под данными правами доступна обработка "Массовое создание актов" и отчёт "Анализ выставленных актов". В обработке "Массовое создание актов" необходимо в качестве периода выбирать предыдущий месяц.
2. Для пользователя Кадровик-расчетчик установите права Кадровик-расчетчик. Данные права позволяют установить оклад, процент премий и график работы сотрудникам. Производить  начисления заработной платы, премий, отпускных, выплаты всех начислений, удержания НДФЛ, учёт отпусков. Доступны Отчёты по Расчетам с сотрудниками, по Выработке специалистов и Расход запланированных отпусков.
3. Для пользователя Менеджер установите права Менеджер. Данные права позволяют работать с документами Обслуживание клиента. 
4. Для пользователя Специалист установите права Специалист. Данные права позволяют работать с документом Обслуживание. Доступен отчёт по выработке специалистов.
